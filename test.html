🎙️ Indian Voice Speaker Test Page

📖 English Test

Welcome to the Indian Voice Speaker extension test page. This extension converts selected text into natural-sounding Indian speech. Select any text on this page and use the context menu or keyboard shortcut to hear it spoken aloud.

The extension uses the Web Speech API with Indian voices to provide a natural listening experience. It works offline and supports both English and Hindi content.

🎮 How to Test:

  • Method 1: Select any text → Right-click → Click "🎙️ Speak Selected Text"
  • Method 2: Select any text → Press Ctrl+Shift+S (or Cmd+Shift+S on Mac)
  • Method 3: Enable auto-speak in settings → Simply select text to hear it
  • Method 4: Click extension icon → Select text → Click "Speak Selected Text" button

⚙️ Settings to Try:

  • Change voice gender (Male/Female)
  • Adjust speaking speed (0.5x - 2.0x)
  • Toggle auto-speak mode
  • Switch between light/dark theme
  • View and replay speech history
